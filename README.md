# Amazon Sales Analysis Dashboard | Power BI

## 📌 Project Overview
This project focuses on analyzing Amazon sales data using Microsoft Power BI to transform raw data into meaningful business insights. The interactive dashboard helps visualize sales performance, identify trends, and support data-driven decision-making.

## 🎯 Objectives
- Analyze overall sales performance and revenue trends.
- Identify top-performing products and categories.
- Monitor key performance indicators (KPIs).
- Explore sales patterns using interactive visualizations.
- Present business insights through an easy-to-understand dashboard.

## 🛠️ Tools & Technologies
- **Power BI Desktop** – Dashboard development and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and business metrics.
- **Microsoft Excel** – Source data preparation, if applicable.

## 📊 Key Features
- Interactive sales dashboard.
- KPI cards for important sales metrics.
- Charts and graphs for comparing sales performance.
- Filters and slicers for exploring the data.
- Visual analysis to identify sales trends and business opportunities.

## 💡 Skills Demonstrated
- Data cleaning and transformation.
- Data modeling and DAX calculations.
- Interactive dashboard design.
- Business data analysis and visualization.
- Presenting insights for decision-making.


## 📌 Conclusion
This project demonstrates practical Power BI skills by converting sales data into an interactive dashboard for business analysis. It is a portfolio project showcasing data analytics, visualization, and business intelligence capabilities.
